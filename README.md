# WorkforceIQ Analytics – Workforce, Operations & Procurement Dashboard

## Project Overview
WorkforceIQ Analytics is an end-to-end data analytics project built using a synthetic manufacturing dataset. The project analyzes workforce performance, employee attendance, operational efficiency, and procurement activities to generate actionable business insights.

The project demonstrates data analysis skills using SQL Server, Power BI, DAX, and data visualization.

## Tools & Technologies
- **SQL Server:** Data validation, cleaning checks, aggregations, joins, and analytical queries.
- **Power BI:** Interactive dashboards and business reporting.
- **DAX:** Measures and KPI calculations.
- **Excel / CSV:** Dataset preparation and handling.

## Dataset
The project uses synthetic data covering 2025, consisting of five tables:

- Employees
- Monthly Attendance
- Monthly Operations
- Purchase Orders
- Data Dictionary

The dataset is created for portfolio and analytical purposes and does not represent actual company records.

## Dashboard Pages

### 1. Workforce Overview
- Total employees and attrition rate

### 2. Attendance & Operations
- Attendance rate and absence tracking
- Monthly attendance trends

### 3. Procurement & Supplier Analytics
- Total procurement spend
- Monthly purchasing trends
- Supplier-wise spending
- On-time versus delayed deliveries
- Supplier delivery performance

### 4. Executive Overview
- Consolidated business KPIs
- Workforce, attendance, and procurement performance
- Department-level filtering and interactive visuals

## Key Business Insights

- Total workforce: 420 employees.
- Overall employee attrition rate: 17.86%.
- Overall attendance rate: 91.22%.
- Total procurement spend: approximately ₹9.56 crore.
- Overall on-time supplier delivery rate: 58.94%.
- Total operational units processed: 2,241,486.
